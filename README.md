# سجل العقارات

- `index.html`  صفحة إضافة / تعديل عقار
- `view.html`   صفحة العرض مع الفلاتر (سعر، مساحة، جهات، نوع البناء، جمعية)
- `settings.html`  ربط الصفحة بـ GitHub (مرة وحدة)
- `data/data.json`  ملف البيانات الأساسي
- `css/` و `js/`  التصميم والكود

## الحفظ المباشر على data.json
1. اعمل Fine-grained token من GitHub (Contents: Read and write) لهالمستودع فقط.
2. افتح صفحة **إعدادات** وحط اسم الحساب والمستودع والتوكن واضغط "اختبار وحفظ".
3. بعدها أي إضافة أو تعديل أو حذف بينكتب مباشرة بـ data/data.json.

لا ترفع التوكن على GitHub أبداً.
