ربط الصفحة بملف data/data.json على GitHub

بعد الربط، كل عقار بتضيفه أو بتعدله أو بتحذفه بينكتب مباشرة بالملف على GitHub، وكل الناس بتشوفه.

كيف بتعمل التوكن (مرة وحدة)

  1. على GitHub: صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. اختار Only select repositories وحدد المستودع تبعك فقط.
  3. من Repository permissions خلي Contents على Read and write.
  4. انسخ التوكن وحطو فوق. بينحفظ بهالمتصفح فقط، ولا بينرفع مع الملفات.

مهم: لا تكتب التوكن بأي ملف من المجلد ولا ترفعه على GitHub. إذا حطيت التوكن بمتصفح حدا تاني بيقدر يضيف ويعدل، وأي حدا ما عنده توكن بيقدر يشوف بس.
